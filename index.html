Install in 2 minutes.

The beta isn't signed by Apple yet, so macOS asks you to confirm once.

  1. Halto Applications
    Drag to Applications

    Open Halto.dmg and drop the app in.

  2. Privacy & Security “Halto” was blockedOpen Anyway
    Click “Open Anyway”

    System Settings › Privacy & Security.

  3. Accessibility   Halto
    Turn on Accessibility

    So Halto knows which file you point at.

  4. ⌥option
    Hold ⌥ on a file

    The wheel opens. Slide, release, done.

Seeing “Apple could not verify Halto”? That's expected for the beta. Use Open Anyway as shown above, just once.

FAQ

Why does macOS show a warning?

The beta isn't signed with an Apple Developer certificate yet. Everything runs locally and the public release will be signed.

Do my files leave my Mac?

No. Halto only uses tools built into macOS. No files and no statistics are sent.

How do I update?

Download the latest version from this page. It replaces the old one and keeps your settings.

How do I uninstall?

Quit Halto from the menu bar, then move the app to the Trash.
