# Halto – bêta

Site de la bêta de Halto, publié avec GitHub Pages : https://plusjamaisaterre.github.io/Halto-beta/

- `index.html` : page en français, `en/index.html` : page en anglais.
- `assets/` : feuille de style, icône et logo (rendus depuis le dessin de l'app).
- Le bouton de téléchargement pointe vers `releases/latest/download/Halto.dmg` : chaque nouvelle Release de ce dépôt doit contenir un fichier nommé exactement `Halto.dmg`.

Le code de l'app reste dans un dépôt privé. Retours : halto.retours@outlook.com
